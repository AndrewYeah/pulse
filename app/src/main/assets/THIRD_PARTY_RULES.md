# Third-party rule data

The files in `rules/` are a minimal subset distributed by the Karing project
and generated from public GeoSite/GeoIP data. Karing is licensed under GPL-3.0.

- Project: https://github.com/KaringX/karing
- Rule updates: https://github.com/KaringX/karing-ruleset
- Reference revision: 35c2cdb1dec17cfa22f47b919958edaf6c0d7e0b

The application retains the source URL and SHA-256 of every bundled file in
`RuleSetManager`. No Karing name, logo, or application artwork is included.
